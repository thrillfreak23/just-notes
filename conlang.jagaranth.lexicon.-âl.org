$ -âl
*finite verbal suffix :: creates a finite verb*

- usage:
    - with a number or adjective:
       - zipâl- zero.Finite :: to not exist, to sum to zero
       - tokûb zipâlosen-tezh gîgôkechen
       - parse :: thatFar.timeAdverbial zero.Finite.3SgInsapientSubject-ExpectedOutcome \
                  nightrunner.Nominative.unowned.plural
      - translation :: In that distant time, I expect the wild nightrunners to be extinct.
    
    - with a verbal root:
        - barkex- :: gun.Applicative :: shoot
        - barkexâleth-tat Obâremen vêgorotech borûthid ::
        - parse :: gun.Applicative.Finite.3rdSingularSapientSubject-Past Emperor.1stPluralPossesor \
                   wolf.Accusative.unowned Opposite.peace.Adjective
        - translation :: Our Emperor shot the hostile wolf.
    - with a declined nominal:
        - borgîz- :: city.Locative :: borgîzâl- :: be in the city
        - tikûb borgîzâlem ::
        - parse :: this.timeAdverbial city.Locative.Finite.1stSingularSubject
