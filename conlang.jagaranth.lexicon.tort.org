$ tort
verbal root : to know
====
 
- valency :: transitive (to add more is insulting)
- example :: tortâlem borgîz-thenot korodâlem-tezh
- parse :: know.Finite.1SgSubject city.Locative-SubordinateClause.Accusative die.Finite.1SgSubject-ExpectedOutcome
- translation :: I know (that the expected outcome is) that I will die in the city of no one.
