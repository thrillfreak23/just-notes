# âr- 
: verbal prefix :: ToCompletion- marker
- changes the meaning of the verbal root it's attached to
- the actual meaning is always ad hoc

- ## example :: âr-kekaleth-tat Obârem vêgorotech ::
    - parse :: ToCompletion-strike.Finite.3SgSubject-Past Emperor.1SgPossessor wolf.Accusative.Unowned
    - translation :: My Emperor killed the wild wolf.
