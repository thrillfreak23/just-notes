# tezh
: particle adverb :: probably - indicates expected outcome

- Jagaranth has no future tense; the two tenses are past and non-past
- tezh indicates an expected outcome: "I expect this will happen"

- example:
    - kafâlem-sin borgom mûmbid tezh korodâlem
    - parse :: go.Finite.1SgSubject-If city.Dative corpse.Adjective \
               die.Finite.1SgSubject-ExpectedOutcome
    - translation :: If I go to the dead city, I probably will die.
    - note: here ***korodâlem*** is nonpast tense; meaning ***future***
     
    - notes :: more typically -sin is followed by -tod "then"
        - kafâlem-sin borgîn mûmbid korodâlem-tod
        - If I go to the dead city, then I will die.
