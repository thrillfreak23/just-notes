# GENERAL NOTES:

## In the parse, a noun lacking case is nominative because the expression of the nominative is zero.
- Example:
    - î hôkenîz jothor :: 
        - parse and translation :: BE smoke.Locative fire :: Where there's smoke, there's fire.
            - :: in this example the noun for fire, which lacks case, is **jothor** and is nominative singular
